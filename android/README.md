# 玫瑰小手机安卓应用

这是可独立安装的 Android APK，应用 ID 为 `cn.rosepalais.phone`，当前版本 30。
应用界面与素材打包到 APK 内，以应用私有 WebView 存储保存各软件存档；聊天请求仍需用户自己的网络和 API。
浏览器存档不会自动出现在应用中，需用“一键搬家”导出、导入。安装新版本请覆盖安装同一签名的软件，不要先卸载。

## 构建

使用 Python 3 运行 `prepare_tools.py --tools-root <独立工具目录>`。可选 `--proxy <代理地址>`。
脚本从 Eclipse Adoptium 与 Android 官方来源下载 JDK 17、Android 35 平台及构建工具，并核对官方校验值。
再运行 `build_apk.py --tools-root <工具目录> --signing-root <仓库外私有目录> --output <APK路径>`。
无须安装到系统，也不依赖 Gradle 或第三方打包服务。

签名私钥和口令仅保存在 `--signing-root` 指定的仓库外目录。请私下备份；不得上传到公开仓库或加入 APK。
以后必须使用同一签名目录构建，才能覆盖安装并保留原应用数据。

## 文件与权限

- 系统文件选择器支持选图、TXT及搬家文件；备份导出使用系统“保存到”界面，取消/写入失败不会被当作备份成功。
- 麦克风、摄像头只在本地应用页面发起对应操作后申请；外部网站不能获得应用内的媒体授权。
- 禁用任意 file URL 读取、混合HTTP内容和自动系统备份；外部网页在浏览器打开。
- 签名与包结构已验证。需安卓7及以上及较新的系统WebView；真机运行、语音、摄像头、文件选择和具体API服务兼容性尚未实测。

`build/`、SDK、签名材料、浏览器资料均不提交。网页下载目录中只放签名后的公开 APK 和校验值。
