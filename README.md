## v7 玫瑰家园

桌面新增玫瑰家园。点击场景空地移动小人；点菜地播种、浇水、收获，点宠物照料。萝卜、胡萝卜、草莓分别需 1、5、15 分钟，浇一次水即可成熟。离线时间计入作物生长。

初始 40 家园积分，与微信余额独立。每日任务奖励仅领一次；每天可从最多三个不同角色的虚拟菜园各摘一次。宠物同种照料间隔一分钟，照料积累成长值，满 100 长大；伙伴照料为本地操作，不代表实际联网角色。衣帽间支持三种肤色、三种发色和两种发型，衣服购买后永久拥有。

家园数据保存在当前浏览器，包含在“我的小宫殿”导出备份中，暂不跨设备同步。

# 玫瑰小宫殿 · 小手机

浅粉、奶油白与香槟金的私人虚拟手机。纯前端 HTML / CSS / JavaScript，无构建依赖。

## 使用

在项目根目录运行 `python -m http.server 8765 --directory dist`，打开 `http://127.0.0.1:8765/`。

手机桌面包含微信、日历、经期记录、世界书、记忆花园、表情小匣与 API 设置。
微信有聊天、联系人、朋友圈和“我”四页；“我”支持个人头像、昵称、拍一拍、通用聊天背景及虚拟零钱。
首次虚拟零钱余额为 10,000 元；发送红包/转账扣款，领取角色卡片入账，保存收支明细。
原有聊天、角色和图片会在新版继续读取，旧卡片不会追溯扣款。

API 设置分为聊天 API 与语音 API。语音可以共用聊天配置，也可以单独填写地址和密钥。
聊天服务需要兼容 `/chat/completions`；模型发现调用 `/models`。
语音服务需要兼容 `/audio/transcriptions` 和 `/audio/speech`。未填合成模型时使用浏览器朗读。
接口需允许浏览器跨域请求。语音是录音、转写、回复和播放的轮流模式。

长期记忆包括固定信息和 API 自动整理摘要；默认每 24 条新消息或有新消息满一天整理。
关闭页面后不后台运行，重新打开补检查。摘要用于辅助连续聊天，并非逐字无限记忆。

同群角色会互相认识，可点击“自我介绍”公开自己的身份与用户关系。
私聊带入角色参与过的群聊和朋友圈，并在记忆花园提供独立的“共同经历”摘要。
每条群消息保留当时的成员名单，新成员不自动获得旧群记录，其他角色的私聊也不会共享。
原本认识的角色可在世界书的“人物关系”入口登记；程序不自动推断自然语言世界书中的所有关系。
朋友圈支持用户与角色、角色与角色之间的多层回复，只有认识且能看到目标评论的角色可参与。
默认开启发布/评论后的自动互动，每次发布至多 3 条评论和 1 条互相回复，每次评论至多补 1 条回复。
这些互动会调用聊天 API；可关闭自动互动，改为手动选择角色。

朋友圈下方始终显示全部动态，选择角色只决定由谁生成新动态。
点赞、评论自己的动态以及回复自己的评论会显示小粉点和互动通知，可标已读或跳回对应动态。
通知最多保留最近 200 条，消息与动态不因此删除。

表情小匣可上传 JPG/PNG/WebP/GIF 并填写名称和情绪说明，最多 30 个。
图片识别检测会调用当前聊天模型两次，让模型识别随机图片中的色块顺序；未通过时只能用基础表情。
检测结果绑定接口与模型，换接口或模型需重新检测。每轮给识图模型提供至多 6 张表情；聊天可以选择图片回复。
非 GIF 图片缩放后保存；GIF 动画原样保存，限 3 MB；向识图 API 发送时转为首帧 JPEG。

微信“我”里的主动消息默认关闭。页面在前台且空闲时可定时生成一条角色私聊，最多每天设定的条数。
在其他页面收到消息会显示小手机顶部通知；关闭页面后不会继续运行，不提供系统推送。

全局世界书适用于全部角色；局部世界书可绑定角色或指定群聊。常驻与关键词触发均可选择。
世界书是背景设定，聊天记忆由记忆花园整理；角色原有认识关系在人物关系入口登记。

## 数据与发布

用户聊天、图片、日程、经期、记忆和余额保存于当前浏览器，不上传到此仓库，也不跨设备同步。
API 密钥默认留在内存中，勾选记住后存入浏览器；导出备份不包含密钥和解锁密码。
虚拟零钱不涉及真实资金。经期预测仅为日期估计。
进入密码按用户要求暂时关闭，现有托管网站仍保持仅站点所有者可访问。
这个仓库用于代码版本记录，不自动开启 GitHub Pages；托管站点部署单独进行。

## 检查

运行 `npm test`，无需安装依赖；使用 Node.js 22 或更新版本。
测试覆盖模型接口、世界书、记忆调度与失败保留、周期日期、虚拟零钱金额精度、收支防重复、余额不足、存储失败回滚和独立语音凭据。
社交测试覆盖直接关系、不传递认识、评论线程可见性、入群成员快照、共同经历来源、陌生角色拦截、私聊隔离和自动互动上限。
新增检查覆盖全局/角色/群聊世界书范围、通知去重与已读、主动消息时间和次数上限、识图测试判定、自定义表情权限与多模态请求。
浏览器检查覆盖微信导航、拍一拍、红包收支与刷新保留；真实语音仍需使用者提供兼容服务与麦克风测试。
